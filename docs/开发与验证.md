# 开发与验证

SDK 重任务必须通过 GY CrossKit 统一 `ci.py component-run` 的受控 Mac 入口，不直接在候选仓库绕过容量准入。
正式版本 `1.0.0` 待发布。以下为该入口调用的任务合同，不代表该版本已完成验证。

- 源码回归：`:ui-components:testDebugUnitTest`，从本轮 XML 确认实际运行 common 与 Android 测试。
- 编译：Android debug/release、iOS arm64/x64/Simulator arm64、OHOS arm64，均保留宿主工具链版本。
- 归档：`VERSION=1.0.0 bash scripts/archive-prebuilt.sh`，产生 `build/prebuilt/ui-components-maven.tar.gz`。
- 预构建归档采用现有 metadata/check-maven 模板，精确六项 publication，发布后登记真实 SHA256 到 `release-checksums.txt`；未冻结版本必须失败，不使用占位摘要。

`verification-consumer` 是独立构建，默认只从 JitPack 解析精确 `uiComponentsVersion`；候选检查使用 `-PuiComponentsMavenRepo=<staging URL>`。
`-PremoteOnly` 强制 JitPack，不使用 MavenLocal、源码替换或候选仓库。

受控任务运行 `assembleDebug minifyReleaseWithR8 verifyNoCmpUi`，覆盖真实 AAR 编译/D8、R8 和无第二套 UI 的完整依赖图；另运行 `compileKotlinOhosArm64` 与 iOS 编译/链接。
iOS consumer 链接通过 `-PkuiklyRenderFrameworkDir=<真实 2.30.0 Renderer 目录>` 提供匹配的 framework，不以占位符号代替。

源码迁移基线为宿主 SHA `c768cb12c86e59b60fbc69149013850edce509b0`；生产 Kotlin 与回归源码按字节保留。
本轮尚未执行 SDK 编译、独立产物消费、远程公开下载或设备验收；后续收据绑定实际源码/CI SHA 与构建链接。
