# 功能与平台差异

组件完整迁移宿主 `ui-components`：按钮/点击防重、文字/富文本/输入、图片/图标、Checkbox、Label、主题、Dialog、Lazy 列表、刷新、瀑布流、横向分页、选择 Chip、内容状态、自适应布局与悬浮拖动。
源码与 API 保持原包名，不为迁移修改行为；`src/commonTest` 与 `src/androidUnitTest` 保留对应长期回归。

| 范围 | 组件行为 | 宿主职责 |
| --- | --- | --- |
| 字号 | `AppText` / `AppRichText` / 输入样式补偿 iOS 字号；`appFontScale` 保留系统档位并限制上限 | 提供当前系统配置，Android/OHOS 原生 SP 不重复缩放 |
| 图片 | 复用 Kuikly 原生加载器，保留 OHOS tint 矩阵补丁；字节预览可接收有界缩略图 | 素材打包、图片 URL、权限与原始数据预算 |
| Dialog | 继承主题与 CompositionLocal，考虑安全区和键盘 | 注入 `LocalKeyboardHeight` 与 `LocalAppDialogSystemBars` 的真实窗口操作 |
| 输入 | 保留 `skillcurePasswordIconVisible` 原生扩展与公共文本入口 | 原生 receiver 实现与 SDK 配套；本库不注入平台 View |
| Pager / 刷新 | 保留停止旧动画、同页亚像素重发、原生滚动观察器归属与释放 | 单向状态、业务请求、刷新完成 |
| 点击与拖动 | 单调时钟防重、当前回调与受控位置 | 业务操作与页面生命周期 |

这些 SDK workaround 沿用迁移前的语义与移除条件；升级 SDK 前须复验相应用例，不凭版本号删除。
Kuikly Compose 需要的 compiler、腾讯 compose 和共用 Compose runtime 是既有运行条件，不增加第二套 UI 产品。
各端 Renderer 安装、主题/键盘注入和设备表现仍由宿主验收，源码目标声明不等于已完成三端交付。
